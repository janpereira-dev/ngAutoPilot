## Texto de la ficha

NgAutoPilot Skills es un paquete exclusivamente de skills para ingeniería Angular y frontend más segura. Proporciona procedimientos según versión para analizar proyectos, actualizar Angular, arquitectura, pruebas, TypeScript, JavaScript, calidad frontend y validación de releases. No incluye servidor MCP, aplicación conectada ni conexión externa independiente; aporta instrucciones al agente cuando el usuario o el host proporciona contexto del repositorio.
