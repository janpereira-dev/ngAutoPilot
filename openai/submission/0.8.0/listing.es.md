## Texto de la ficha

NgAutoPilot Skills es un paquete exclusivamente de skills para ingeniería Angular y frontend más segura. Incluye procedimientos dependientes de la versión para incorporación de proyectos, actualizaciones Angular, arquitectura, pruebas, TypeScript, JavaScript, calidad frontend y validación de releases. No incluye MCP, aplicaciones conectadas ni conexiones independientes a servicios externos; orienta al agente host con contexto del repositorio proporcionado por el usuario o el host.

## Peticiones iniciales

1. Usa NgAutoPilot para identificar la skill de ingeniería mínima pertinente y proponer una validación acotada.
2. Inspecciona este repositorio Angular y recomienda el siguiente paso seguro más pequeño.
3. Planifica una actualización major Angular y separa la modernización.
